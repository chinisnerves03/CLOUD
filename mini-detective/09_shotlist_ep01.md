# Shot List — Entry 1: The Button That Wasn't There

Source: `06_scripts_ep01-10.md` (Entry 1). Runtime about 40s + 2s end card. Format 9:16, paper cut-out collage, layered for parallax. Palette: kraft #C89B6D, navy #1F2A44, mustard #E0A526, tomato #C8452F, cream #F3E9D2, teal #2F8F8B.

Global animation rules
- Animate on twos (12 fps look): every paper piece moves in small steps, slight wobble (1-2 px jitter) on edges.
- Camera moves are slow push/pan on layers, never smooth 3D. Drop shadows shift with parallax.
- Pip is the only character that blinks. Juno never stands still (small bob).
- Each shot lists: layers to build, motion, audio. Characters use rigged sheets from `02_characters.md`.

Needed assets: Button Square background (BG/MG/FG), empty plinth (separate layer), crowd silhouettes (6-8 cut-outs, reusable), Pip rig (neutral, curious, surprised), Juno rig (smirk), magnifier, clue card (keyhole eye), thread (separate long strip), pencil-stub clock tower, end card.

Notes for the animator
- Shots 2 and 9 reuse the same plaza background. Build once, push camera differently.
- Shot 7 and shot 8 must read as the same mark: draw the keyhole eye once, scale it for both.
- The thread in shots 9-10 is a separate strip layer so it can twitch alone. It must look different from the red thread bunting (pale cream with a faint gold fleck).
- Keep Pip at 1/4 frame height or less in wide shots; the city should feel big around him.

Timing check
The script is about 40s. If the voice read comes out long, cut shot 3 first (hold shot 2 instead), then trim shot 5 to 3s. Prompt A6 in the prompt library handles line trimming.
