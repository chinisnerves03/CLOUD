# Pip Thimble, Tiny Detective — คลังข้อมูลซีรีส์ (Series Vault)

ซีรีส์อนิเมชันตัดแปะภาษาอังกฤษสำหรับคลิปสั้นแนวตั้ง ตอนละ 30–45 วินาที เล่าเรื่องแบบนักสืบตัวจิ๋วที่กำลังไล่ตามคดีเล็กๆ ซึ่งซ่อนความลับที่ใหญ่มากไว้ข้างใต้

โฟลเดอร์นี้เป็น **แหล่งข้อมูลหลักที่เดียว** ใช้ได้ทั้งในเครื่อง (local) และบน cloud เพราะทุกอย่างเป็นไฟล์ข้อความ Markdown ที่ copy-paste ไปใช้กับโมเดลใดก็ได้

## แผนที่ไฟล์

| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `00_MASTER_PRIMER.md` | **วางไฟล์นี้ก่อนทุกครั้ง** ในแชทใหม่ (cloud หรือ local) เพื่อให้โมเดลรู้ canon ทั้งหมด |
| `01_series_bible.md` | แนวคิด โทน โครงตอน ธีม แผนโพสต์ |
| `02_characters.md` | ตัวละครทั้งหมด ลักษณะ นิสัย พร้อม prompt สร้างภาพ |
| `03_locations.md` | ฉากและสถานที่ พร้อม prompt สร้างพื้นหลัง |
| `04_voice_cast.md` | เสียงพากย์ ElevenLabs (พร้อม voice_id) และวิธีเขียนบทให้เข้ากับเสียง |
| `05_episodes_01-10.md` | พล็อตซีซัน 1 ตอนที่ 1–10 |

| `08_knowledge_base.md` | canon log, continuity, ความลับของเรื่อง, backlog ไอเดีย, ตารางสถิติ |

## วิธีใช้ (ทำซ้ำทุกตอน)

1. เปิดแชทใหม่ แล้ววาง `00_MASTER_PRIMER.md`
2. สั่งเขียนตอนใหม่ด้วย prompt A1 ใน `07_prompt_library.md`
3. ตรวจ continuity ด้วย prompt A5
4. สร้างภาพที่ต้องใช้ (prompt กลุ่ม B), ใช้ภาพอ้างอิงตัวละครเดิมเสมอ
5. สร้างเสียงทีละบรรทัดด้วย ElevenLabs (กลุ่ม D) แล้วต่อใน editor
6. ทำอนิเมชันตามกลุ่ม C แล้วโพสต์ด้วยแคปชันกลุ่ม E
7. อัปเดต `08_knowledge_base.md`: canon log, continuity, ตารางสถิติ

## ใช้กับ local vs cloud

- **Local (Ollama, LM Studio):** ใช้ `00_MASTER_PRIMER.md` เป็น system prompt. ถ้า context สั้น ให้ใส่เฉพาะตอนที่เกี่ยวข้อง
- **Cloud:** วาง primer แล้วอ้างอิงไฟล์อื่นตามต้องการ หรือเปิดโปรเจกต์ที่เชื่อมกับ repo นี้
- **ซิงก์:** ใช้ git เป็นต้นฉบับเดียว (แก้ในเครื่อง, push, cloud เห็นข้อมูลเดียวกัน)

## ข้อควรระวัง

- ตัวละคร ชื่อ และดีไซน์ทั้งหมดเป็นของต้นฉบับ ห้ามนำตัวการ์ตูนหรือภาพมีลิขสิทธิ์ของผู้อื่นมาผสม
- เพลงและเสียงประกอบต้องใช้ของที่มีสิทธิ์ใช้งานเท่านั้น
- เสียงใน `04_voice_cast.md` เลือกจากรายชื่อและคำอธิบาย ยังไม่ได้ฟังจริง ควรลองฟังก่อนล็อก
- ส่วน "Secret canon" ใน `08_knowledge_base.md` เป็นร่าง แก้ได้ และอย่าวางให้โมเดลที่เขียนบท ถ้าไม่ต้องการให้เฉลยก่อนเวลา
- ซีรีส์โตช้ากว่าคลิปไวรัลเดี่ยวในช่วงแรก ใช้เป็นเกมระยะยาว ไม่ใช่เป้า 100k ใน 14 วัน
