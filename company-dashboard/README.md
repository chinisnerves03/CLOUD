# ห้องควบคุม AI ลัดมือ (Dashboard เฟส 1)

หน้าเว็บ (Artifact บน claude.ai) สำหรับดูคลิป/ผลสำรวจ และสั่งงานเอเจนต์จากมือถือ
ลิงก์: https://claude.ai/artifact/Vs5mKMdWjk7nWHiKBjzmNF (เปิดได้เฉพาะบัญชีเจ้าของ เปิดผ่านแอป Claude บน iPhone)

## ใช้งาน
- **ภาพรวม** จำนวนงานรอคิว/กำลังทำ/เสร็จ และงานล่าสุด
- **คลิป** รายการคลิป 14–27 กดขยาย "กรอกผล/แก้สถานะ" เพื่อใส่ยอดดู, % ดูจนจบ, % skip, หมายเหตุ และติ๊กว่าลง IG/YouTube แล้ว
- **สำรวจ** กด "สำรวจเพิ่ม" เพื่อค้นคลิปไทยที่ยอดโดดเด่นผ่าน vidIQ (ใช้ 5 เครดิต มีกล่องยืนยันก่อน) ผลเก็บไว้ในหน้า
- **สั่งงาน** เลือกเอเจนต์ → พิมพ์คำสั่ง → ส่งงาน งานที่ใช้เครดิตมีกล่องยืนยันก่อน
- **บันทึก** ประวัติงานทั้งหมด ปุ่ม "ส่งอีกครั้ง", "ทำเสร็จแล้ว", "ลบ"

## แท็บ IG (เชื่อม Instagram ผ่าน vidIQ)
1. เชื่อม Instagram กับบัญชี vidIQ ที่ https://app.vidiq.com ก่อน (ตอนตรวจครั้งล่าสุดยังไม่มีบัญชีเชื่อมอยู่)
2. กด **ตรวจการเชื่อมต่อ** (ฟรี) จะเห็นบัญชีและว่าลงรีลได้/ดึงสถิติเจ้าของได้ไหม
3. กด **ดึงสถิติ** (ฟรี) ได้ยอดดู, % ดูจนจบ, % skip, แชร์, เซฟ ของรีลล่าสุด 12 อัน แล้ว **ผูกกับคลิป** เพื่อให้ตัวเลขเข้าแท็บคลิปอัตโนมัติ
4. **ลงรีล** ต้องมีลิงก์วิดีโอสาธารณะ (HTTPS .mp4 หรือลิงก์ YouTube) เพราะอัปโหลดไฟล์จากเครื่อง/GitHub ส่วนตัวตรงๆ ไม่ได้ กล่องยืนยันแสดงบัญชี วิดีโอ แคปชั่น ป้าย AI ก่อนโพสต์ และถ้าผิดพลาดจะหยุด ไม่ลองซ้ำเอง

**ยังไม่ได้ทดสอบกับบัญชีจริง:** ชื่อฟิลด์ในผลสถิติ (ยอดดู/skip/จนจบ) เป็นการเดาจากคำอธิบายเครื่องมือ ครั้งแรกให้ดู "ข้อมูลดิบ" ใต้รายการแล้วบอกผมเพื่อปรับ และการลงรีลจริงยังไม่เคยรัน (ทดสอบกับตัวจำลองเท่านั้น)

## เอเจนต์ (ไฟล์คำสั่งตั้งต้นอยู่ที่ `agents/`)
ตัวสำรวจช่อง (vidIQ) · ตัวทำคลิป (ElevenLabs + HyperFrames) · ตัวเขียนแพ็กเกจโพสต์ · ตัววิเคราะห์ผล
แก้คำสั่งตั้งต้นที่ไฟล์ `.md` แล้วรัน `python3 build.py` และเผยแพร่ `dashboard.html` ใหม่

## การสั่งงานทำงานอย่างไร
กดส่ง → หน้าเก็บงานในฐานข้อมูล (`tasks`) → เรียก Claude Code Remote `create_session` เปิดเซสชันใหม่บน repo `chinisnerves03/CLOUD` พร้อมคำสั่งของเอเจนต์
ถ้าเรียกไม่ได้ งานจะค้างสถานะ "รอคิว" พร้อมข้อความบอกวิธี: พิมพ์ในแชทกับ Claude ว่า **"ทำคิว"** แล้ว Claude อ่านคิวจากฐานข้อมูลและทำให้

## ยังไม่ได้ทดสอบจริง (บอกตรงๆ)
- การเรียก Claude Code Remote และ vidIQ จากหน้าเว็บ (ผลทดสอบอัตโนมัติใช้ตัวจำลอง) ครั้งแรกบนมือถือจะมีหน้าขอสิทธิ์ ให้กดอนุญาต
- รูปแบบผลลัพธ์ของ `create_session` ว่าคืนรหัสเซสชันในรูปแบบไหน (หน้าลองอ่านหลายแบบ ถ้าไม่เจอจะเก็บสถานะกำลังทำโดยไม่มีรหัส)
- เซสชันที่เปิดจากหน้าจะอัปเดตสถานะกลับมาที่หน้าเองไม่ได้ ต้องกด "ทำเสร็จแล้ว" หรือให้ Claude อัปเดตให้ ผลงานจะอยู่ใน GitHub (PR แบบ draft)
- เซสชันใหม่อาจไม่มีเครื่องมือเรนเดอร์ครบ (Node, FFmpeg, HyperFrames)

## ข้อควรระวัง
- แชร์หน้านี้แบบ "ดูอย่างเดียว" เท่านั้น ผู้ที่เขียนฐานข้อมูลได้สามารถสร้างงานที่คุณอาจกด "ส่งอีกครั้ง" โดยไม่ตั้งใจ
- ไม่เก็บรหัสผ่านหรือคีย์ในหน้า ตัวเลขผลลัพธ์ของคลิปต้องกรอกเอง
- แผนก UDC เป็นเฟส 2
