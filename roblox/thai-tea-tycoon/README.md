# Thai Tea Tycoon — สคริปต์ชุดแรก (Roblox / Luau)

ระบบที่มีในชุดนี้: **จองฐานอัตโนมัติ · ร้านขายเองได้ตั้งแต่เริ่ม (เงินเข้าตลอดไม่ต้องยืนชง) · ชงเองจากหลังเคาน์เตอร์ Brew Station (กด E) เพื่อได้เงินเร็วขึ้น · ลูกค้าเดินมาต่อคิวซื้อชาหน้าร้าน · อัปเกรด 3 สาย: จ้างพนักงานมาขายแทน / สูตรดีขึ้น (เงินต่อแก้ว) / บริการเร็วขึ้น · แผ่นสร้างของที่อยู่ด้านหลังของชิ้นถัดไป · เซฟด้วย DataStore · รายได้ออฟไลน์ (พนักงานขายต่อ) · Game Pass 4 อัน · Developer Product 2 อัน · หน้าจอเงิน + ลูกศรนำทาง · แสงและบรรยากาศ + ขอบมน**

**ข้อความในเกม ชื่อของ ป้าย และข้อความใน Output เป็นภาษาอังกฤษทั้งหมด** (คอมเมนต์ในโค้ดก็เป็นอังกฤษ) ส่วน README นี้ยังเป็นภาษาไทย

ตัวเลขเศรษฐกิจ (คำนวณใน `Config.lua`): 45 เลเวล, ของชิ้นแรก ฿80, ราคาเลเวล 45 = ฿22M

**วงจรหาเงิน:** ร้านขายเองตั้งแต่วินาทีแรก (Counter sales เงินเข้าตลอดไม่ว่าจะยืนตรงไหน) → ลูกค้าเดินมาต่อคิวหน้า Brew Station ร้านเสิร์ฟเองทุก ~2.5 วินาที อยากได้เร็วขึ้นก็เดินไปหลังเคาน์เตอร์ (ยืนบนพรมสีส้ม "BREW HERE") แล้วกดชง ทุกแก้วที่ชงจะเสิร์ฟลูกค้าคนหน้าทันที → เงินพอก็เหยียบแผ่นอัปเกรดสีฟ้า/ส้ม/ม่วงข้าง Brew Station (ซื้อซ้ำได้) → พนักงานโผล่มายืนขายให้ที่แถวรถเข็นข้างๆ (มี +฿ ลอยขึ้น) → เหยียบแผ่นเขียวที่อยู่ด้านหลังของชิ้นถัดไปเพื่อสร้างร้าน
- เงินต่อแก้ว: ฿2 (เลเวล 1) → ฿17,000 (เลเวล 45) เพิ่มทุกครั้งที่สร้างของ และ Better Recipe เพิ่มอีก +10% ต่อเลเวล
- อัปเกรด (ราคา = ฐาน × อัตราโต^ที่มี): Hire Staff ฿300 ×3.5 สูงสุด 6 คน (คนละ 1 แก้ว/3 วินาที) · Better Recipe ฿800 ×3.0 สูงสุด 15 · Faster Service ฿1,500 ×3.2 สูงสุด 10 (+8% ต่อเลเวล) · ร้านขายเอง (Counter sales) 25% ของเส้นรายได้หลัก คูณ Recipe/Speed/2x ด้วย
- จำลองผู้เล่นที่ซื้ออันถูกสุดก่อน: ชิ้นแรกได้ใน ~30 วินาทีแม้ไม่ชงเลย, สร้างครบ ≈ **40 นาที** ถ้าชงเองด้วย หรือ ≈ 70 นาที ถ้าไม่ชงเลย
- ปรับได้ที่ `BREW_COOLDOWN`, `BREW_SHARE`, `PASSIVE_SHARE`, `STAFF_INTERVAL`, `Config.UPGRADES`

> **สถานะการทดสอบ (29 ก.ย. 2026):** รันใน Roblox Studio จริงแล้ว ผ่าน Studio MCP ไม่มีข้อความสีแดงใน Output
> ผ่านเช็กลิสต์: สร้างฐาน 6 ฐาน · เงินขึ้นเอง · ลูกค้าเดินบนพื้น หันถูกทาง ต่อคิวหน้า Brew Station · ชงได้เฉพาะบนพรมส้ม (ยืนหน้าเคาน์เตอร์ห่างพรม ~6 studs กด E แล้วไม่ได้เงิน) · จ้างพนักงาน/อัปเกรด/แผ่นเขียว · เซฟแล้วโหลดกลับมาได้
> คำเตือนที่ยังเหลือ (ตั้งใจ): Max Players ยังไม่ใช่ 6 และ Game Pass ID ยังเป็น 0

## 1) เตรียมโปรเจกต์ใน Roblox Studio
1. เปิด Studio → เทมเพลต **Baseplate**
2. เปิด API สำหรับเซฟข้อมูลตอนทดสอบ: **Home → Game Settings → Security → Enable Studio Access to API Services**
   (ถ้าไม่เปิด เกมยังเล่นได้ แต่จะไม่เซฟ และมีคำเตือนใน Output)
3. **Max Players = 6** (ตรงกับจำนวนฐาน) Studio รุ่นใหม่ย้ายช่องนี้ไปไว้บนเว็บแล้ว: Creator Hub → Creations → เกม → Places → เพลส → Configure Place → Server Fill / Max Players
4. **Explorer → Lighting → Properties → LightingStyle = Realistic** และติ๊ก **PrioritizeLightingQuality** (Studio รุ่นใหม่ใช้สองช่องนี้แทน Technology = Future) สคริปต์ตั้งบรรยากาศ แสงฟุ้ง และสีให้เองอยู่แล้ว ถ้าอยากใช้แสงของตัวเองให้ตั้ง `Config.SETUP_LIGHTING = false`
5. `Workspace.StreamingEnabled = true` ตั้งให้อัตโนมัติผ่าน Rojo (`default.project.json`)

### ทางลัด: sync อัตโนมัติด้วย Rojo (ไม่ต้องคัดลอกทีละไฟล์)
มีไฟล์ `default.project.json` ให้แล้ว ทำครั้งเดียวบนเครื่องที่ใช้ Studio:
1. ติดตั้ง Rojo: ดาวน์โหลดจาก https://rojo.space (หรือ `aftman add rojo-rbx/rojo` / `rokit add rojo-rbx/rojo`) แล้วติดตั้ง Rojo plugin ใน Studio (แท็บ Plugins → Manage Plugins หรือ `rojo plugin install`)
2. `git clone` repo นี้ลงเครื่อง แล้วในโฟลเดอร์ `roblox/thai-tea-tycoon` รัน `rojo serve`
3. ใน Studio เปิดเพลส → แท็บ Plugins → Rojo → **Connect** สคริปต์ทั้ง 8 ตัวจะเข้าไปอยู่ถูกที่เอง
4. ทุกครั้งที่อัปเดต: `git pull` แล้ว Studio จะเปลี่ยนตามทันทีขณะเชื่อมต่ออยู่ (ของอื่นที่สร้างเองใน Studio จะไม่ถูกลบ)

## 3) กด Play ทดสอบ

สิ่งที่ควรเห็น: ตัวละครเกิดที่ลานกลาง → เดินผ่านซุ้มประตู "THAI TEA TYCOON" → ลูกค้าต่อคิวหน้าเคาน์เตอร์ Brew Station → ลูกศรเหลืองชี้พรมสีส้มหลังเคาน์เตอร์ → ยืนบนพรมแล้วกด E ชงชา (+฿2 ข้างยอดเงิน ลูกค้าคนหน้ารับแก้วแล้วเดินออก) → ถึง ฿80 ลูกศรชี้แผ่นเขียวด้านหลังจุดของ Folding Table → ถึง ฿300 ลูกศรชี้แผ่นสีฟ้า Hire Staff → พนักงานคนแรกโผล่มาขายที่รถเข็นข้าง Brew Station

**จำนวน Part:** ประมาณ 4,950 ต่อฐานเมื่อซื้อครบ (รวมพนักงาน 6 คน ตัวละครแบบละเอียด และขอบมน) รวม 6 ฐาน + ลานกลาง ≈ 30,000 ของที่ยังไม่ซื้อเก็บอยู่ใน ServerStorage ไม่ถูกวาด ลูกค้าที่เดินต่อคิวสร้างบนเครื่องผู้เล่นแต่ละคน (สูงสุด ~5 คนต่อฐาน เฉพาะฐานที่มีเจ้าของและอยู่ใกล้กล้อง) ไม่กินเน็ตเซิร์ฟเวอร์
เพื่อให้มือถือไม่กระตุก แนะนำเปิด **Workspace → StreamingEnabled = true** (ใน Properties ของ Workspace) เครื่องผู้เล่นจะโหลดเฉพาะบริเวณใกล้ตัว ชิ้นเล็กถูกปิดเงาไว้แล้ว

ทดสอบหลายคน: แท็บ **Test → Clients and Servers → 2 Players → Start**

## 4) ใช้โมเดลที่ทำเอง (ไม่บังคับ)
ถ้าอยากใช้โมเดลที่ปั้นเองหรือซื้อมาแทนโมเดลจาก `ItemModels`:
สร้าง `Workspace > Plots` (Folder) แล้วใส่ Model ชื่อ `Plot1`..`Plot6` โดยแต่ละฐานต้องมี:
- `Items` (Folder) — โมเดลของที่ซื้อ ตั้งชื่อ **`L02` ถึง `L45`** วางไว้ตำแหน่งที่ต้องการให้โผล่ (ระบบจะย้ายไปซ่อนใน ServerStorage ก่อน แล้วย้ายกลับมาเมื่อซื้อ)
- `PadSlots` (Folder) — Part ชื่อ `Pad1` (แผ่นซื้อของ ขนาดแนะนำ 6×0.5×6) ระบบจะย้ายแผ่นไปตาม `ItemModels.PadSpots` ถ้าฐานมี Part ชื่อ `Base` (พื้นฐาน) ถ้าไม่มี แผ่นจะอยู่ที่เดิม
- `BrewStation` (Model) — ต้องมี Part ชื่อ `Kettle` ข้างใน ถ้ามี Part ชื่อ `BrewPad` (จุดยืนหลังเคาน์เตอร์) ปุ่ม "Brew Tea [E]" จะอยู่ที่ BrewPad และต้องยืนบนนั้นถึงชงได้ ถ้าไม่มีจะใส่ปุ่มที่ Kettle และชงได้จากรอบ ๆ ถ้ามี Part ใส ๆ ชื่อ `QueueStart` (หันด้าน -Z ออกไปทางลูกค้า) ลูกค้าจะมาต่อคิวจากจุดนั้น
- `Upgrades` (Folder) — Part ชื่อ `Staff`, `Recipe`, `Speed` (แผ่นอัปเกรด) รถเข็นพนักงานระบบสร้างให้เองตาม `ItemModels.StaffSpots` (ต้องมี `Base`)
- `Sign` (Part) — ป้ายชื่อเจ้าของ มี SurfaceGui + TextLabel ข้างใน (ไม่บังคับ)

ทำฐานแรกให้เสร็จแล้วคัดลอกเป็น 6 ฐาน แถวล่างหมุน 180° ให้หันหน้าเข้าลานกลาง (ฐานจากระบบกว้าง 100 × ลึก 130)
เมื่อมี `Workspace.Plots` แล้ว ระบบจะไม่สร้างฐานจำลองอีก (ตั้ง `BUILD_PLACEHOLDER_PLOTS = false` ได้เลย)
ถ้าขาดโมเดล เช่น ยังไม่ได้ทำ `L17` ระบบจะเตือนใน Output แล้วข้ามไป ไม่พัง (ซื้อได้ปกติ แค่ไม่มีอะไรโผล่)

### หน้าร้านค้าในเกม (ShopClient)
ปุ่ม **SHOP** สีส้มกลางขอบซ้ายของจอ กดแล้วเปิดหน้าต่าง "Thai Tea Shop" มีการ์ด Game Pass 4 ใบ และ Cash Boost 2 ใบ (โค้ดอยู่ที่ `StarterPlayerScripts/ShopClient.client.lua`)
- ปุ่มบนการ์ด: ID เป็น 0 → "Coming soon" (กดไม่ได้) · ใส่ ID แล้ว → แสดงราคา "R$ xx" ที่ดึงจาก Roblox เอง · ซื้อ Pass แล้ว → "Owned"
- การ์ด Cash Boost บอกยอดเงินที่จะได้ตามเลเวลตอนนี้ เช่น "+฿9,000 now"
- ชื่อ คำอธิบาย สี และตัวอักษรบนวงกลมแก้ได้ใน `Config.PASSES` / `Config.PRODUCTS` (`Name`, `Desc`, `Color`, `Badge`) ถ้ามีรูปไอคอนให้ใส่ `Icon = "rbxassetid://..."` จะใช้รูปแทนวงกลม ลำดับการ์ดอยู่ใน `PASS_ORDER` / `PRODUCT_ORDER`
- หน้าต่างย่อเองบนจอเล็ก (มือถือ) และเลื่อนขึ้นลงได้

Developer Product ให้ของแค่ครั้งเดียวต่อใบเสร็จ (จำ `PurchaseId` 50 ใบล่าสุดไว้ในข้อมูลผู้เล่น) และจะตอบ Roblox ว่าให้ของแล้วก็ต่อเมื่อเซฟสำเร็จ

## ระบบให้ผู้เล่นกลับมาเล่น (Retention)
ตั้งค่าทั้งหมดอยู่ใน `Config.lua` หัวข้อ Retention เงินรางวัลคิดเป็น "วินาทีของรายได้หลัก" ของผู้เล่นคนนั้น จึงคุ้มทุกเลเวล และมีขั้นต่ำ (`Min`) สำหรับร้านใหม่
- **Rebirth** (`Config.REBIRTH`): สร้างครบเลเวล 45 แล้ว ปุ่มม่วง **REBIRTH** จะขึ้นด้านล่าง กดแล้วมีหน้าต่างยืนยัน → ร้านกลับเป็นเลเวล 1 เงิน/อัปเกรดเป็น 0 แต่รายได้ทุกทาง +50% ถาวรต่อครั้ง (x1.5, x2, x2.5 …) ผลรวมอยู่ในเงินต่อแก้ว ร้านขายเอง พนักงาน ออฟไลน์ และ Cash Boost
- **รางวัลรายวัน** (`Config.DAILY`): ปุ่ม **DAILY** เหนือปุ่ม SHOP รับได้ทุก 20 ชม. ถ้ารับภายใน 48 ชม. จะนับวันต่อเนื่อง (สูงสุด 7) รางวัล = รายได้ 2 นาที × วันที่ (ขั้นต่ำ ฿300 × วันที่) ตอนเข้าเกมถ้ารับได้จะมีข้อความเตือน
- **โค้ด** (`Config.CODES`): ปุ่ม **Codes** ใต้ปุ่ม Music พิมพ์ตัวเล็ก/ใหญ่ก็ได้ ใช้ได้คนละครั้ง ตอนนี้มี `THAITEA` (รายได้ 5 นาที) · `WELCOME` (2 นาที) · `BOBA` (10 นาที) ใส่ `Expires = <unix time>` ถ้าอยากให้โค้ดหมดอายุ
- **ภารกิจสั้น ๆ** (`Config.QUESTS`): แผงภารกิจใต้กรอบเงิน ทำทีละภารกิจ (ชง X แก้ว / สร้างของ / ซื้ออัปเกรด / หาเงินให้ได้ X) ครบแล้วได้รางวัลทันทีและขึ้นภารกิจถัดไป วนกลับต้นลิสต์เมื่อจบ ภารกิจที่ทำไม่ได้ (เช่น สร้างของตอนครบ 45 แล้ว) จะถูกข้าม
- **กระดานอันดับ** (`Config.LEADERBOARDS`): ป้ายไม้ 2 แผ่นกลางลาน หันเข้าหาจุดเกิด "Top Earners" (เงินที่หาได้ทั้งหมดจากการชงและรายได้) และ "Most Rebirths" ใช้ OrderedDataStore อัปเดตทุก 2 นาที (`LEADERBOARD_REFRESH`) และตอนผู้เล่นออก ถ้าอยากวางเองให้สร้าง `Workspace.Leaderboards` แล้วใส่ Model ชื่อ `TopEarners` / `TopRebirths` ที่มี Part ชื่อ `Board` (ตัวหนังสืออยู่ด้าน Front)
- **รายชื่อผู้เล่น** (มุมขวาบนของ Roblox) โชว์ Level และ Rebirths ของทุกคน กรอบเงินจึงย้ายมาไว้กลางขอบขวา

ข้อมูลที่เซฟเพิ่ม: `Rebirths`, `TotalEarned`, `LastDaily`, `DailyStreak`, `Codes`, `QuestIndex`, `QuestProgress`, `QuestTarget` (เซฟเก่าโหลดได้ ค่าที่ไม่มีจะเริ่มจาก 0)

## 6) ข้อจำกัดที่ต้องรู้ก่อนปล่อยจริง
- **ยังไม่มีโลก 2** — หลังเลเวล 45 ผู้เล่นทำได้แค่ Rebirth แล้วเล่นฐานเดิมซ้ำ (เร็วขึ้นเพราะตัวคูณ)
- **ไม่มีลูกค้า NPC / ลูกค้า VIP / ไรเดอร์ที่เดินได้** (พนักงานและมอเตอร์ไซค์ในฐานเป็นโมเดลตั้งนิ่ง) รายได้คำนวณจากตัวเลขล้วน ๆ ไม่ได้มาจากลูกค้าที่เดินมาซื้อ
- โมเดลทั้งหมดยังไม่เคยเห็นใน Studio จริง: ถ้าชิ้นไหนหน้าตาเพี้ยน (เช่น ร่มหรือหลังคากลับหัว) ให้แคปหน้าจอมา จะแก้ที่ `ItemModels.lua`
- **DataStore แบบง่าย** ไม่มีระบบล็อกเซสชัน ถ้าผู้เล่นคนเดียวเข้าสองเซิร์ฟเวอร์พร้อมกันอาจเซฟทับกัน ก่อนเปิดจริงแนะนำเปลี่ยนไปใช้ **ProfileStore/ProfileService**
- ถ้าโหลดข้อมูลไม่สำเร็จ (DataStore ล่ม) ผู้เล่นจะเริ่มจากศูนย์ชั่วคราวและ **ระบบจะไม่เซฟทับ** ข้อมูลเดิม
- เงิน ราคา และการซื้อคำนวณที่ **ฝั่งเซิร์ฟเวอร์ทั้งหมด** ไคลเอนต์แค่แสดงผล จึงแก้ตัวเลขโกงจากฝั่งผู้เล่นไม่ได้ แต่ยังไม่มีระบบตรวจจับการวาร์ป/ความเร็วผิดปกติ
- ยังไม่ได้ทดสอบบนมือถือจริงและยังไม่ได้ปรับประสิทธิภาพสำหรับเครื่องสเปกต่ำ

## ผังการทำงานโดยย่อ
```
Main → DataService.Load → Monetization.LoadPasses → PlotService.AddPlayer (จองฐาน, แสดงของตามเลเวล, คิดรายได้ออฟไลน์)
PlotService: ปุ่ม Brew (ProximityPrompt) → เงินเข้ายอดเงิน | ลูป (ทุก 0.1 วิ): ร้านขายเอง + พนักงานเข้ายอดเงิน → (มี Auto Build และเงินพอ → สร้างเลย) → เช็กว่าเหยียบแผ่นสร้างของ/แผ่นอัปเกรดไหม → ซื้อ → ย้ายแผ่น/โชว์พนักงาน → อัปเดต Attribute ให้ไคลเอนต์
ClientMain: อ่าน Attribute (Cash/Level/Income/BrewValue/Staff/Recipe/Speed/Plot) → แสดงเงิน + ข้อความนำทาง + ลูกศร (Brew Station → แผ่นอัปเกรดที่ซื้อได้ → แผ่นสร้างของ) + "+฿" ลอยเหนือพนักงาน + ลูกค้าเดินต่อคิว (โคลนจาก ReplicatedStorage.CustomerTemplates ที่ Main สร้าง)
RemoteEvent ReplicatedStorage.TycoonNotify: เซิร์ฟเวอร์ส่งข้อความแจ้งเตือน (Buy/Collect/Error/Offline) ให้ไคลเอนต์
```
