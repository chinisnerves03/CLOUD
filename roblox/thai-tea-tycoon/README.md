# Thai Tea Tycoon — สคริปต์ชุดแรก (Roblox / Luau)

ระบบที่มีในชุดนี้: **จองฐานอัตโนมัติ · ชงชาเองที่ Brew Station (กด E) · กระเป๋าเงินมีความจุ ต้องเดินไปฝากที่ COLLECT CASH · รายได้อัตโนมัติ (น้อยกว่า) · แผ่นซื้อ 1 แผ่นที่ย้ายไปอยู่ตรงจุดของชิ้นถัดไป · เซฟด้วย DataStore · รายได้ออฟไลน์ · Game Pass 3 อัน · Developer Product 2 อัน · หน้าจอเงิน + ลูกศรนำทาง**

**ข้อความในเกม ชื่อของ ป้าย และข้อความใน Output เป็นภาษาอังกฤษทั้งหมด** (คอมเมนต์ในโค้ดก็เป็นอังกฤษ) ส่วน README นี้ยังเป็นภาษาไทย

ตัวเลขเศรษฐกิจ (คำนวณใน `Config.lua`): 45 เลเวล, ของชิ้นแรก ฿80, ราคาเลเวล 45 = ฿22M

**วงจรหาเงิน:** ชงชาที่ Brew Station (กด E ทุก 0.35 วินาที) → เงินเข้ากระเป๋า → เดินไปฝากที่ COLLECT CASH → ใช้ซื้อของบนแผ่นเขียว
- เงินต่อแก้ว: ฿3 (เลเวล 1) → ฿33,000 (เลเวล 45) เพิ่มขึ้นทุกครั้งที่ซื้อของ
- กระเป๋าจุได้ 80 แก้ว (ประมาณ 28 วินาทีของการชง) เต็มแล้วต้องไปฝาก
- รายได้อัตโนมัติ = 25% ของเส้นรายได้หลัก (฿2.5/s → ฿2,750/s) เข้ายอดเงินตรงโดยไม่ต้องฝาก
- เวลาซื้อครบ ≈ **47 นาทีถ้าชงตลอด** (ไม่นับเวลาเดินไปฝาก) หรือ ≈ 3.5 ชั่วโมงถ้า AFK อย่างเดียว
- ปรับได้ที่ `BREW_COOLDOWN`, `BREW_SHARE`, `PASSIVE_SHARE`, `BAG_BREWS`

> **สถานะการทดสอบ:** ทุกไฟล์ผ่านการคอมไพล์ด้วย `luau-compile` และตรวจด้วย `luau-analyze` (เหลือแค่คำเตือนเรื่อง global ของ Roblox ที่ตัวตรวจนอก Studio ไม่รู้จัก)
> รัน `Config.lua` เช็กตารางราคา/รายได้แล้ว (ชงตลอด ≈ 47 นาที, AFK ≈ 3.5 ชม.)
> แต่ **ยังไม่เคยรันใน Roblox Studio จริง** จึงอาจมีบั๊กตอนรัน ถ้าเจอ error ให้คัดลอกข้อความสีแดงจากหน้าต่าง Output มาแก้ต่อ

## 1) เตรียมโปรเจกต์ใน Roblox Studio
1. เปิด Studio → เทมเพลต **Baseplate**
2. เปิด API สำหรับเซฟข้อมูลตอนทดสอบ: **Home → Game Settings → Security → Enable Studio Access to API Services**
   (ถ้าไม่เปิด เกมยังเล่นได้ แต่จะไม่เซฟ และมีคำเตือนใน Output)
3. **Game Settings → Players → Max Players = 6** (ตรงกับจำนวนฐาน)

## 3) กด Play ทดสอบ
ตอนนี้ `Config.BUILD_PLACEHOLDER_PLOTS = true` ระบบจะ **สร้างฐาน 6 ฐานพร้อมโมเดลของครบ 44 ชิ้นให้เอง** (จาก `ItemModels.lua` ประกอบจาก Part ล้วน ไม่ต้องลากโมเดลเข้าเอง)

สิ่งที่ควรเห็น: ตัวละครเกิดที่ลานกลาง → เดินผ่านซุ้มประตู "THAI TEA TYCOON" → ลูกศรเหลืองชี้ไปที่ BREW STATION → กด E ชงชา (เงินเด้ง +฿3 ที่มุมจอ) → กระเป๋าเต็ม/พอซื้อแล้ว ลูกศรชี้ไป COLLECT CASH → เหยียบเพื่อฝาก → ลูกศรชี้แผ่นเขียวที่อยู่ตรงจุดของชิ้นถัดไป → เหยียบเพื่อซื้อ → ของโผล่ แผ่นย้ายไปจุดของชิ้นต่อไป

ผังฐาน (กว้าง 100 × ลึก 130 studs ด้านหน้าหันเข้าลานกลาง): Brew Station + COLLECT CASH อยู่แถวหน้า → รถเข็น (ขั้น 1) ซ้าย + เคาน์เตอร์ (ขั้น 2) ขวา → คาเฟ่ (ขั้น 3) → ครัวกลาง (ขั้น 4) → ตึกใหญ่ (ขั้น 5) แถวหลังสุด จุดวางแผ่นซื้อของแต่ละชิ้นอยู่ใน `ItemModels.PadSpots` (เช็กด้วยโค้ดแล้วว่าไม่ทับของที่ซื้อไปก่อน)
**อาคารเดินเข้าได้ 8 หลัง** มีของข้างในครบ: ครัวกลาง ห้องเย็น โรงงาน ศูนย์กระจายสินค้า HQ (ล็อบบี้ + เห็นโต๊ะทำงานทุกชั้นผ่านกระจก) สาขาห้าง สนามบิน ตึกแก้วชาไทย (ล็อบบี้)
ตำแหน่งทุกชิ้นแก้ได้ที่ `ItemModels.Layout` ส่วนหน้าตาแก้ได้ที่ฟังก์ชัน `Build.Lxx` ของชิ้นนั้น ของตกแต่งส่วนกลาง (ซุ้มประตู กรอบแผ่นซื้อ บูธเก็บเงิน ไฟทาง ต้นไม้ ม้านั่ง น้ำพุ) อยู่ใน `Decor`

**จำนวน Part:** ประมาณ 2,800 ต่อฐานเมื่อซื้อครบ รวม 6 ฐาน + ลานกลาง ≈ 17,400 ของที่ยังไม่ซื้อเก็บอยู่ใน ServerStorage ไม่ถูกวาด
เพื่อให้มือถือไม่กระตุก แนะนำเปิด **Workspace → StreamingEnabled = true** (ใน Properties ของ Workspace) เครื่องผู้เล่นจะโหลดเฉพาะบริเวณใกล้ตัว ชิ้นเล็กถูกปิดเงาไว้แล้ว

ทดสอบหลายคน: แท็บ **Test → Clients and Servers → 2 Players → Start**

## 4) ใช้โมเดลที่ทำเอง (ไม่บังคับ)
ถ้าอยากใช้โมเดลที่ปั้นเองหรือซื้อมาแทนโมเดลจาก `ItemModels`:
สร้าง `Workspace > Plots` (Folder) แล้วใส่ Model ชื่อ `Plot1`..`Plot6` โดยแต่ละฐานต้องมี:
- `Items` (Folder) — โมเดลของที่ซื้อ ตั้งชื่อ **`L02` ถึง `L45`** วางไว้ตำแหน่งที่ต้องการให้โผล่ (ระบบจะย้ายไปซ่อนใน ServerStorage ก่อน แล้วย้ายกลับมาเมื่อซื้อ)
- `PadSlots` (Folder) — Part ชื่อ `Pad1` (แผ่นซื้อของ ขนาดแนะนำ 6×0.5×6) ระบบจะย้ายแผ่นไปตาม `ItemModels.PadSpots` ถ้าฐานมี Part ชื่อ `Base` (พื้นฐาน) ถ้าไม่มี แผ่นจะอยู่ที่เดิม
- `BrewStation` (Model) — ต้องมี Part ชื่อ `Kettle` ข้างใน ระบบจะใส่ปุ่ม "Brew Tea [E]" ให้ที่ Kettle
- `Register` (Part) — COLLECT CASH จุดฝากเงินจากกระเป๋า
- `Sign` (Part) — ป้ายชื่อเจ้าของ มี SurfaceGui + TextLabel ข้างใน (ไม่บังคับ)

ทำฐานแรกให้เสร็จแล้วคัดลอกเป็น 6 ฐาน แถวล่างหมุน 180° ให้หันหน้าเข้าลานกลาง (ฐานจากระบบกว้าง 100 × ลึก 130)
เมื่อมี `Workspace.Plots` แล้ว ระบบจะไม่สร้างฐานจำลองอีก (ตั้ง `BUILD_PLACEHOLDER_PLOTS = false` ได้เลย)
ถ้าขาดโมเดล เช่น ยังไม่ได้ทำ `L17` ระบบจะเตือนใน Output แล้วข้ามไป ไม่พัง (ซื้อได้ปกติ แค่ไม่มีอะไรโผล่)

## 5) เปิดใช้ Game Pass / Developer Product
| Key ใน Config | ชนิด | ผล |
|---|---|---|
| `PASSES.DoubleCash` | Game Pass | รายได้ x2 |
| `PASSES.AutoCollect` | Game Pass | Auto Deposit: ชงแล้วเงินเข้ายอดเงินเลย ไม่ต้องเดินไปฝาก |
| `PASSES.OfflinePlus` | Game Pass | รายได้ออฟไลน์ 100% สูงสุด 24 ชม. (ปกติ 50% สูงสุด 8 ชม.) |
| `PRODUCTS.CashSmall` | Developer Product | เงินเท่ารายได้หลัก 10 นาที (ขั้นต่ำ ฿1,000) |
| `PRODUCTS.CashBig` | Developer Product | เงินเท่ารายได้หลัก 1 ชั่วโมง (ขั้นต่ำ ฿10,000) |

1. Creator Dashboard → สร้าง Game Pass 3 อัน และ Developer Product 2 อัน
2. นำ ID ไปใส่ใน `Config.PASSES` และ `Config.PRODUCTS` (ราคาตั้งที่หน้า Dashboard ไม่ได้อยู่ในโค้ด)
3. อยากลองผลของ Pass ใน Studio ให้ตั้ง `STUDIO_GRANT_ALL_PASSES = true` จะได้ Pass ทุกอัน (ไม่กระทบเกมที่ปล่อยจริง) ค่าเริ่มต้นเป็น `false` เพื่อให้เช็กลิสต์ข้อ 3 ตรง (ถ้าเปิด ได้เงิน x2 และเงินที่ชงเข้ายอดเงินเลยโดยไม่ต้องไปฝาก)
4. ใส่ `rbxassetid://...` ของเสียงใน `Config.SOUNDS` ถ้าต้องการเสียงซื้อของ/เก็บเงิน/ซื้อไม่ได้
5. **ยังไม่ได้ทำปุ่มขายในเกม** (ต้องเรียก `MarketplaceService:PromptGamePassPurchase` / `PromptProductPurchase` จากปุ่ม UI) ตอนนี้ระบบรับซื้อ/ให้ของทำงานแล้ว แต่ยังไม่มีปุ่มให้ผู้เล่นกด

Developer Product ให้ของแค่ครั้งเดียวต่อใบเสร็จ (จำ `PurchaseId` 50 ใบล่าสุดไว้ในข้อมูลผู้เล่น) และจะตอบ Roblox ว่าให้ของแล้วก็ต่อเมื่อเซฟสำเร็จ

## 6) ข้อจำกัดที่ต้องรู้ก่อนปล่อยจริง
- **ไม่มีรีเบิร์ธ / โลก 2 / ภารกิจรายวัน** — ถึงเลเวล 45 แล้วเกมจบแค่นั้น
- **ไม่มีลูกค้า NPC / ลูกค้า VIP / ไรเดอร์ที่เดินได้** (พนักงานและมอเตอร์ไซค์ในฐานเป็นโมเดลตั้งนิ่ง) รายได้คำนวณจากตัวเลขล้วน ๆ ไม่ได้มาจากลูกค้าที่เดินมาซื้อ
- โมเดลทั้งหมดยังไม่เคยเห็นใน Studio จริง: ถ้าชิ้นไหนหน้าตาเพี้ยน (เช่น ร่มหรือหลังคากลับหัว) ให้แคปหน้าจอมา จะแก้ที่ `ItemModels.lua`
- **DataStore แบบง่าย** ไม่มีระบบล็อกเซสชัน ถ้าผู้เล่นคนเดียวเข้าสองเซิร์ฟเวอร์พร้อมกันอาจเซฟทับกัน ก่อนเปิดจริงแนะนำเปลี่ยนไปใช้ **ProfileStore/ProfileService**
- ถ้าโหลดข้อมูลไม่สำเร็จ (DataStore ล่ม) ผู้เล่นจะเริ่มจากศูนย์ชั่วคราวและ **ระบบจะไม่เซฟทับ** ข้อมูลเดิม
- เงิน ราคา และการซื้อคำนวณที่ **ฝั่งเซิร์ฟเวอร์ทั้งหมด** ไคลเอนต์แค่แสดงผล จึงแก้ตัวเลขโกงจากฝั่งผู้เล่นไม่ได้ แต่ยังไม่มีระบบตรวจจับการวาร์ป/ความเร็วผิดปกติ
- ยังไม่ได้ทดสอบบนมือถือจริงและยังไม่ได้ปรับประสิทธิภาพสำหรับเครื่องสเปกต่ำ

## ลองเล่นในเบราว์เซอร์ (ไม่ต้องใช้ Roblox)
`tools/web-demo/` สร้างหน้าเว็บที่เล่นได้จริงจากโมเดลและสูตรเศรษฐกิจเดียวกับเกม (เดิน เก็บเงิน เหยียบแผ่นซื้อ ดูของโผล่) เป็นเดโมเท่านั้น ไม่มีการชนกับของ ไม่มีผู้เล่นคนอื่น และมีปุ่ม Speed ไว้เร่งเวลา
สร้างใหม่หลังแก้โมเดล: รัน `tools/preview/build.sh` แล้ว `python3 tools/web-demo/build.py` จะได้ `web-demo.html`

## ผังการทำงานโดยย่อ
```
Main → DataService.Load → Monetization.LoadPasses → PlotService.AddPlayer (จองฐาน, แสดงของตามเลเวล, คิดรายได้ออฟไลน์)
PlotService: ปุ่ม Brew (ProximityPrompt) → เงินเข้ากระเป๋า | ลูป (ทุก 0.1 วิ): รายได้อัตโนมัติเข้ายอดเงิน → เช็กว่าเหยียบ COLLECT CASH/แผ่นไหม → ฝาก/ซื้อ → ย้ายแผ่นไปจุดถัดไป → อัปเดต Attribute ให้ไคลเอนต์
ClientMain: อ่าน Attribute (Cash/Bag/BagMax/Level/Income/BrewValue/Plot) → แสดงเงิน กระเป๋า + ข้อความนำทาง + ลูกศรชี้ทาง (Brew Station → COLLECT CASH → แผ่นซื้อ)
RemoteEvent ReplicatedStorage.TycoonNotify: เซิร์ฟเวอร์ส่งข้อความแจ้งเตือน (Buy/Collect/Error/Offline) ให้ไคลเอนต์
```

## ปรับเศรษฐกิจ
แก้ใน `Config.lua`: `FIRST_PRICE`, `LAST_PRICE`, `FIRST_WAIT`, `WAIT_GROWTH` แล้วดูผลใน Output บรรทัด `[Config] ...` ตอนกด Play (บอกเวลารอรวม)
ชื่อของ 44 ชิ้นอยู่ใน `ITEM_LIST` (ลำดับ = เลเวล 2..45, ตัวเลขหลังชื่อ = ขั้น 1–5 ใช้กำหนดสีบล็อกจำลอง)
