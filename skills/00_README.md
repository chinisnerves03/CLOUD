# Skills pack: make a BeamNG.drive mod popular

Goal: everything needed to build, release, film, post, measure and grow a BeamNG.drive mod. Not only modding: video editing, short-form, SEO, analytics, community, legal, money.

## How to use
Each file is a self-contained skill (YAML front matter: `name`, `description`). Copy a file into `.claude/skills/<name>/SKILL.md` to let Claude load it automatically, or paste it into a chat as a briefing.

## Honesty note
Written from general knowledge, not from a live check of BeamNG or any platform. Game internals (jbeam keys, Lua API names, folder rules), platform limits (video length, hashtag counts, algorithm behaviour) and repository rules change between versions. Items marked **[verify]** must be checked against the current BeamNG docs / platform help before you rely on them. Nothing here was tested in-game.
