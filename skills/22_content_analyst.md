# Content analyst method

## Loop
Question -> Data -> Pattern -> Hypothesis -> Test -> Decision. Write each step down in one table.

## Data to collect per post
date/time, platform, format, length, hook type, topic/car, thumbnail style, caption style, impressions, reach, views, 3-s view rate, average watch time, % viewed, likes, comments, shares, saves, follows, link clicks, downloads (if traceable).

## Read the numbers
| Signal | Diagnosis |
|--------|-----------|
| Low impressions | distribution not triggered: topic/format/hook/posting consistency |
| Impressions ok, low 3-s rate | weak hook or mismatch with audience |
| Good 3-s, drop at 3-8 s | the beat after the hook fails (see editing skills) |
| Good retention, low shares/saves | content entertains but has no utility or emotion |
| High saves/shares | content has value -> repeat the angle |
| High views, low downloads | CTA/mod page problem |
Compare to **your own median**, not to other creators; raw benchmarks vary **[verify]**.

## Outlier analysis
Find posts (yours and competitors') at 3x+ the account median. Deconstruct: hook, first 3 s, cut rate, text, sound, topic, comment themes. Count how many outliers share a trait before calling it a pattern (n >= 5).

## Retention curve reading
Cliff in first second = hook; slope = pacing; bump = rewatch moment (good); flat end = good payoff, loop works.

## Sampling caution
One post proves nothing. Compare at least 5-10 posts per variant; remove outliers caused by one-off events; wait 48-72 h.

## Reporting (1 page)
1. Headline result (one number + change vs last period)
2. Top 3 / bottom 3 posts and why
3. Insight (pattern, confidence: low/med/high)
4. Next actions (max 3), owner and date
5. Risks/unknowns

## Tools
Native insights (IG, TikTok, YouTube Studio), a spreadsheet, vidIQ-style tools, UTM/short links. Keep raw data; never rely on screenshots only.
