# YouTube SEO & thumbnails

## Search + browse
Two traffic sources: **search** (people typing "best BeamNG mods", "<car> BeamNG") and **browse/suggested** (driven by click-through and watch time). Optimise both.

## Keywords
- Seed terms: BeamNG mod names, car models, "BeamNG drive", "BeamNG mods 2026", "best/new/free".
- Check autocomplete and a keyword tool (vidIQ/TubeBuddy-style) for volume vs competition **[verify availability]**.
- Target long-tail ("BeamNG touge map Thai" beats "BeamNG").

## Title (≤ 60 characters visible)
- Keyword near the start, curiosity or benefit after: "This BeamNG Mod Changes Drifting Forever".
- Honest. No fake claims; honest titles protect retention.
- Test 2–3 variants; rename after 48 h if CTR is weak.

## Thumbnail
- 1280×720. One clear subject (the car), strong contrast, 3–4 words max, face/emotion optional.
- Consistent brand: colours, font, logo placement.
- Check at tiny size on a phone; if unreadable, simplify.
- Never mislead; the video must deliver the thumbnail promise within 30 s.

## Description template
```
Line 1-2: hook + keywords + download info.
Download: <where>   Mod page: <link>
Chapters: 00:00 Intro ...
Social/Discord links
Credits & music licences
AI voice / sponsorship disclosures if used
```

## Chapters & engagement
- Chapters help retention and search snippets.
- Pin a comment with the link and a question to start discussion.
- End screens → next video; playlists per mod series.

## Upload checklist
- [ ] Title, thumbnail, description, chapters, tags (few, relevant)
- [ ] Subtitles (SRT) + language set
- [ ] Category Gaming, audience "not for kids" unless applicable
- [ ] Cards/end screen
- [ ] Share to community tab / other platforms 30 min after launch
