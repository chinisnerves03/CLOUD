# ชุด prompt สำหรับทำคลิปแนวตั้ง (รวบรวมจากที่ทำจริงในโปรเจกต์ AI ลัดมือ)

ใช้วางให้ AI ช่วยทำงานทีละขั้น ปรับ [ในวงเล็บ] ให้ตรงกับสินค้าของคุณ

## 0) กฎที่ใช้กับทุกคลิป (วางไว้ต้นแชต)
```
คุณช่วยทำคลิปสั้นแนวตั้ง 9:16 (1080x1920) ความยาว 20-30 วินาที ภาษาไทย ให้ [ชื่อเพจ/สินค้า]
กฎ: ห้ามรับประกันรายได้/ยอดขาย ห้ามรีวิวปลอม ห้ามยอดขายปลอม ห้ามความขาดแคลนปลอม
ห้ามราคา "ลดจาก" ที่ไม่เคยขายจริง ถ้าใช้ร้านตัวอย่างต้องติดป้าย "ตัวอย่างร้านสมมติ"
ทุกคลิปจบด้วยการชวนคอมเมนต์คีย์เวิร์ดเดียว: [คีย์เวิร์ด]
```

## 1) หาแนวที่ได้ผลก่อนทำ
```
ช่วยสรุปแนวคลิปไทยที่ยอดดูสูงกว่าค่ากลางของช่องตัวเองมากในหัวข้อ [หัวข้อ]
แยกเป็น: สูตรเปิด 3 วินาทีแรก, รูปแบบ (จอแยก/ก่อน-หลัง/ลิสต์/POV แชท), วิธีเรียกคอมเมนต์
ใช้เฉพาะคลิปตัวอย่างที่ฉันให้ ห้ามเดาตัวเลข และบอกว่ายังไม่ยืนยันถ้าไม่มีข้อมูล
```
แนวที่เจอว่าได้ผลในกลุ่ม AI ไทย: แจกของฟรีให้คอมเมนต์คีย์เวิร์ด, จอแยกสอนใช้ AI, "ถ้าพิมพ์ X จะได้ Y", ลิสต์เซฟได้ ห้ามลอกแนวโชว์รายได้

## 2) เขียนสคริปต์ 25 วินาที
```
เขียนสคริปต์คลิป 25 วินาทีเรื่อง [หัวข้อ] แบ่ง 5-6 ฉาก ฉากละ 3-5 วินาที
ให้แต่ละฉากมี: ข้อความบนจอ (สั้น ไม่เกิน 8 คำ), บทพากย์ (1 ประโยค)
ฉากแรกต้องหยุดคนดูใน 2 วินาที ฉากสุดท้ายเป็น CTA "คอมเมนต์คำว่า [คีย์เวิร์ด]"
ใช้เฉพาะข้อมูลจริงที่ให้: [ข้อมูล]
```

## 3) แนวคลิป 3 แบบที่ใช้แล้ว
- **POV แชทเด้ง:** ฉาก 1 ตัวอักษรใหญ่ "POV ..." → ฉากแชทลูกค้า-ร้าน (ติดป้ายร้านสมมติ) → "ให้ AI ร่าง คุณตรวจแล้วกดส่ง" → รายการหมวดสินค้า → CTA
- **ก่อน-หลัง:** คำถามเปิด → การ์ดแบบแย่ (สั่งสั้นๆ) → ความลับ/วิธี (รายการ 4 ข้อ) → การ์ดแบบดี → "AI ให้ร่างแรก คุณเป็นเจ้าของคำสุดท้าย" → CTA
- **3 ข้อห้าม/ข้อควรระวัง:** หัวข้อเตือน → ข้อ 1 → เพิ่มข้อ 2 → เพิ่มข้อ 3 → "เช็กลิสต์ก่อนโพสต์" → CTA

## 4) ทำภาพ + เสียง (ที่ใช้จริง)
```
สร้างสเปกคลิปเป็น JSON: scenes[] แต่ละฉากมี type (title | chat | split | list | cta), ข้อความ และ dur
บทพากย์ภาษาไทยต่อฉาก เสียง th-TH-NiwatNeural (edge-tts) rate +10%
ความยาวฉาก = ความยาวเสียงฉากนั้น + 0.45 วินาที (ขั้นต่ำ 2.2)
เรนเดอร์ด้วย Chrome headless 30fps ทีละเฟรม แล้วรวมกับเสียงด้วย ffmpeg (libx264, yuv420p, aac)
```
ไฟล์โค้ด: `premium/promo/engine.html`, `render.js`, `make.py` (รัน `python make.py <ชื่อคลิป>` ต้องตั้ง env PW และ WORK)

ข้อควรระวังที่เจอจริง:
- ชื่อคลาส CSS ซ้ำกัน (`.s` ของฉากกับของฟองแชท) ทำให้ฟองเด้งหลุดกรอบ ให้ตั้งชื่อต่างกัน
- ป้ายปุ่มของ ManyChat ยาวได้ไม่เกิน 20 ตัวอักษร
- IG เว็บครอบวิดีโอเป็นสี่เหลี่ยมโดยค่าเริ่มต้น ต้องกดเลือกอัตราส่วน 9:16 ที่หน้า "ครอบตัด" ก่อนกดถัดไป

## 5) แคปชัน
```
เขียนแคปชัน IG สำหรับคลิปนี้: บรรทัดแรกเป็นประโยคเปิด, 1 ประโยคบอกประโยชน์จริง,
ปิดด้วย "คอมเมนต์ [คีย์เวิร์ด] [สิ่งที่จะได้]" และแฮชแท็ก 3-4 อัน ห้ามอ้างผลลัพธ์เกินจริง
```

## 6) ลงคลิปและตั้งตอบอัตโนมัติ
1. IG เว็บ → สร้าง → โพสต์ → เลือกไฟล์ → ครอบตัด 9:16 → ถัดไป ×2 → ใส่แคปชัน → แชร์
2. ManyChat → Auto-DM links from comments → เลือกโพสต์ → คีย์เวิร์ด → Opening DM + DM พร้อมปุ่มลิงก์ (ป้ายไม่เกิน 20 ตัวอักษร) → ตรวจ → Go Live
3. เลือกเฉพาะโพสต์ที่ต้องการ อย่าใช้ "any post" ถ้าคีย์เวิร์ดสั้น (เช่น pro) เพราะอาจชนกับคลิปอื่น
