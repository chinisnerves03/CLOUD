# ตั้งค่า ManyChat: คอมเมนต์ "prompt" → DM พร้อมลิงก์ชุดคำสั่งฟรี

หมายเหตุ: หน้าจอและชื่อเมนูของ ManyChat เปลี่ยนได้ ถ้าไม่ตรงกับด้านล่างให้ดูหน้า Help ของ ManyChat ล่าสุด เงื่อนไขแผนฟรี/ราคาให้ตรวจเองที่หน้า pricing (ผมไม่ยืนยันตัวเลข)
ใช้ได้กับ IG/FB เท่านั้น ใช้กับ YouTube ไม่ได้ ห้ามส่งรหัสผ่านให้ใคร ล็อกอินเองเท่านั้น

## 0) เตรียมก่อน
- [ ] IG @ailadmue เป็นบัญชี Professional (Business หรือ Creator)
- [ ] เชื่อมกับ Facebook Page (ManyChat ต้องใช้)
- [ ] ใน IG: Settings → Messages and story replies → Message controls → Connected tools → เปิด "Allow access to messages"
- [x] ไฟล์ PDF อัปโหลดขึ้น Drive แล้ว (`prompt-pack-21.pdf`) ตั้ง "ทุกคนที่มีลิงก์ ดูได้" แล้ว: https://drive.google.com/file/d/1vg-r7gkogy-i7gEA88Xmfg2X9QLe0SmJ/view?usp=sharing

## 1) เชื่อมบัญชี
1. เข้า app.manychat.com → สมัคร/ล็อกอินด้วย Facebook
2. Connect Instagram → เลือก @ailadmue → อนุญาตสิทธิ์
3. ตรวจว่าขึ้นสถานะเชื่อมต่อแล้ว

## 2) สร้าง Automation (ทำ 1 อันต่อ 1 โพสต์)
ManyChat เลือกได้เฉพาะโพสต์ที่โพสต์แล้ว ดังนั้นโพสต์ก่อนแล้วค่อยตั้ง

1. Automations → New Automation → เทมเพลต/ทริกเกอร์ **Instagram: Comment on a post or reel**
2. เลือกโพสต์/รีลที่ต้องการ
3. คีย์เวิร์ด: `prompt` (ไม่สนตัวพิมพ์เล็กใหญ่) เลือกแบบ "contains"
4. เปิดตอบคอมเมนต์สาธารณะ (สุ่ม 3 แบบ):
   - ส่งทางแชตแล้วนะครับ 📩
   - ดูในข้อความได้เลยครับ
   - เช็กแชตได้เลยครับ 🎁
5. **Opening DM** (ข้อความแรก):
   > ขอบคุณที่สนใจครับ 😊 กดปุ่มด้านล่างแล้วผมส่งลิงก์ชุดคำสั่ง AI 20 แบบให้เลยครับ ✨

   ปุ่ม: `ขอลิงก์เลย`
6. **ข้อความถัดไป** (หลังกดปุ่ม):
   > นี่ครับ ชุดคำสั่ง AI 20 แบบ 🎁 คัดลอก แก้ [ในวงเล็บ] แล้วใช้ได้ทันที ถ้าชอบ ฝากกดติดตาม @ailadmue ไว้ด้วยนะครับ ✨

   ปุ่มลิงก์: `เปิดชุดคำสั่ง` → ลิงก์ PDF จากข้อ 0
7. ส่งเฉพาะลิงก์ที่สัญญาไว้ ไม่แอบใส่โปรโมชันอื่น และอย่าตั้งให้ส่งถี่ผิดปกติ (กฎของ Meta)

## 3) ทดสอบก่อนเปิด Live
- ใช้บัญชี IG อื่น คอมเมนต์ `prompt` ใต้โพสต์ → ต้องได้ตอบคอมเมนต์ + DM + ลิงก์เปิดได้
- ถ้าไม่ได้ DM: ตรวจ "Allow access to messages", สิทธิ์ที่ให้ ManyChat, และว่าบัญชีทดสอบไม่ได้ถูกจำกัด
- ผ่านแล้วค่อยกด **Live**

## 4) จับคู่โพสต์
สร้าง 1 automation ต่อโพสต์ (ชื่อ automation ใช้ชื่อคลิป เช่น "clip29 vague prompt") คลิปที่ยังไม่โพสต์ให้จดว่า "รอโพสต์"
